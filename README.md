## This isn't a pipe

... and I'm not really here anymore. 👻 

I'm still keeping this account around if I need to interact with projects on Github, but I've moved all my projects [elsewhere](https://code.on.nilsnh.no/). 🐬

[You can learn about my motivation here](https://nilsnh.no/2024/07/15/divesting-from-github-and-going-self-hosted/). In short, I argue that Github and its owner Microsoft constitute an unhealthy centralizing force on the open source movement. Thus, I'm voting with my feet and taking my projects, time and attention away from this platform.

See also: [giveupgithub.org](https://giveupgithub.org/)
